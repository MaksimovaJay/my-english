# MJay English

Персональный интерактивный учебник английского. Пока работает без бэкенда: прогресс хранится в localStorage браузера. Синхронизация через Supabase запланирована, см. `docs/superpowers/specs/2026-09-25-cloud-sync-and-homework-review-design.md`.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Тесты

```bash
npm run test
```

## Структура

Меню: Главная · Темы · Повторение · Домашка · Прогресс.

- **Темы** (`/topics`) разбиты на две группы: «Пройдено на уроках» и «Новое / не изученное». Внутри темы есть вкладки Слова · Фразы · Правило · Упражнения и блок «Тренировать»: карточки, написание, на слух, «Найди пару», «Лови слова».
- **Повторение** (`/review`) содержит карточки на сегодня, «Мои ошибки» и «Все слова и игры».

## Как добавляется материал

Учебный материал живёт в коде, в `lib/seed/`:

| Файл | Что там |
|---|---|
| `topics.ts` | список тем (`group: 'class'` — пройдено, `'extra'` — новое) |
| `words.ts`, `extraWords.ts` | слова; тема задаётся полем `category` = id темы |
| `phrases.ts` | фразы |
| `grammar.ts` | правила и упражнения из книги; тема задаётся полем `topicId` |

1. Пришлите фото страницы из книги в чат Claude Code.
2. Claude добавит слова, правило и упражнения в подходящую тему (или создаст новую), а затем запушит изменения.
3. При следующем открытии `mergeSeed` добавит новое на любом устройстве. Прогресс по уже изученным словам сохраняется.

Домашку пока можно загрузить JSON-файлом в разделе «Домашка».

## Известные ограничения

- Прогресс хранится отдельно на каждом устройстве (до перехода на Supabase).
- Ошибки из домашки не попадают автоматически в «Мои ошибки».
- Правила и упражнения нельзя редактировать из интерфейса, только через код.
